LANGKAH 3 — CHECKLIST PERSIAPAN TAHAP 0 (DRAFT)

PASANG
1. Hentikan backend: Ctrl+C.
2. Backup folder backend.
3. Extract ZIP, copy kandungan folder backend ke backend asal, pilih Replace. Jangan buat backend/backend. .env tidak berubah.
4. Dalam terminal backend:
   npm run typecheck
   npm test
   npm run dev
   Ada 33 ujian API, semuanya sepatutnya lulus.

UJIAN PERTAMA — BACA DAHULU
Login semula sebagai Penyedia melalui Postman jika token tamat.
GET http://localhost:5000/api/paket/3/checklist-persiapan
Authorization: Bearer Token Penyedia.
Body: none.
Klik Send. Akan keluar 25 item, jawapan null jika belum diisi, versi 0 dan pengisian_id null. GET sahaja tidak mencipta rekod pengisian.

Import backend/postman/Jala-Mutu-Langkah-3.postman_collection.json.

ATURAN
- Penyedia menyimpan checklist bagi paket DRAFT. PIC/Admin/Direktorat membaca mengikut akses paket yang telah ditetapkan.
- PIC Balai lain tidak boleh melihat rekod atau jawapan. Endpoint mengembalikan 404 jika paket tidak boleh diakses.
- Jawapan dibenarkan: "Ya", "Tidak" atau null. Tiada jawapan palsu diwajibkan untuk menyimpan draft. null mengosongkan jawapan; "Tidak" ialah jawapan yang sah.
- Hantar 1–25 jawapan setiap request; jangan ulang item_id. Item mesti daripada template Tahap 0.
- Keterangan maksimum 2000 aksara. Jika tidak dihantar, catatan lama kekal; string kosong mengosongkan catatan.
- Simpanan separa tidak memadam jawapan item lain.
- Setiap simpanan menaikkan versi; versi lama ditolak dengan 409. Baca semula dan tentukan perubahan yang hendak dihantar; jangan overwrite tanpa semak.
- Status, peratus, pencipta, template dan bukti_dokumen_id tidak boleh dihantar melalui endpoint simpan.
- Status pengisian berasingan daripada paket. Simpan checklist tidak mengubah paket menjadi Diajukan/Disetujui.
- Simpanan checklist, jawapan, versi dan audit berada dalam satu transaksi.

TEMPLATE DAN HAD LANGKAH INI
1 template kerja, revisi DRAFT-01, dengan 25 item berdasarkan frontend: telaah data awal, rencana lapangan, koordinasi dan dokumen persiapan.
Penetapan item wajib/bersyarat BELUM diaktifkan: wajib bernilai null. Jangan gunakan template kerja ini untuk kelulusan sebenar sehingga syarat lingkup survei dan dokumen telah disahkan.
persen_terisi hanya mengira Ya/Tidak yang diisi; bukan peratus lulus dan bukan bukti dokumen telah dimuat naik. syarat_submit_aktif sentiasa false untuk langkah ini.
Belum termasuk N/A bersyarat, upload bukti, submit, review, pindah tahap atau sambungan UI.
