---
name: Urutan audit diagram
description: Cara membaca perbedaan tingkat rincian diagram ringkasan dan diagram penyerahan.
---

Gunakan urutan diagram rinci 03 untuk audit: audit internal Penyedia Jasa 100% → upload → status VALID → audit Pengguna Jasa → audit Direktorat. Jangan menjadikan VALID prasyarat audit internal.

**Why:** Diagram ringkasan menampilkan audit sebagai satu tahap umum, tetapi diagram rinci 03 menempatkan B1–B3 sebelum UP/SV dan C1 setelah SV. Menganggap seluruh audit terjadi setelah upload membuat alur internal salah.

**How to apply:** Saat mengubah gerbang audit, penyerahan, atau navigasi tahap, cocokkan kembali dengan diagram rinci, bukan hanya urutan tahap pada diagram ringkasan.
